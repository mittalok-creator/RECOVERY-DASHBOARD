Upload your daily NPA export (the HO "e-AB NPA AC WISE" .csv/.xlsx) — it's parsed automatically. Optionally also upload the Customer Master (Address/Aadhar/PAN) whenever it refreshes; it's remembered between updates so you don't need to re-upload it daily.

Tap to choose the Head Office Daily NPA Projection workbook or the Branch Advance file
.xlsx (Daily Follow-up Sheet) or .csv — Sol ID, Advance (₹ Lakhs), optionally NPA March/June (₹ Lakhs)

Upload the Head Office Daily NPA Projection workbook as-is, or the Branch Advance template filled in by hand — the Sol ID and Advance columns are read automatically (from the "Daily Follow-up Sheet" for the HO workbook). If the file also has "NPA MARCH 26"/"NPA JUNE 26" columns (₹ Lakhs), those power a Mar/Jun comparison shown in the Dashboard's Total Outstanding card. Branches are matched by Sol ID, not name, so this stays correct even where branch name spellings differ between reports. Uploading replaces the previous figures. Goes live the next time you hit Publish.

Interest Reversal (master list) — not loaded yet
Tap to choose the Interest Reversal file
.xlsx or .csv — Account_Number, Interest Reversal amount (₹)

This is now the permanent source for the Interest Reversal figure — every future daily NPA upload will automatically apply it by Account Number, overriding whatever (if anything) Head Office's own file carries that day, so it never silently resets to 0 again. Only re-upload this when you have an updated/corrected list; you do not need to upload it alongside every daily NPA file. Goes live the next time you hit Publish.

Address List (Account No. or Customer ID → Address) — not loaded yet
Tap to choose the Address List file
.xlsx or .csv — Account Number or Customer ID, Address

One list, uploaded once, used app-wide — whenever an account's address is still blank after Customer Master and carry-forward, this list fills it in, by Account Number first and by Customer ID if that doesn't match (a row only needs one of the two, not both — useful if your source list is one address per customer rather than per account). Also used directly by the Branch Split utility tool (Utility Hub), in both Simple and Full NPA Split modes. Uploading replaces the previous list entirely and applies immediately, no separate Apply step. Goes live app-wide the next time you hit Publish.

Branch Contacts (Manager / Recovery Officer) — not loaded yet
Tap to choose the Branch Contacts file
.xlsx or .csv — Sol ID, Branch Manager, Recovery Officer, and whatever else has been collected

The downloaded template already has every branch's Sol ID, Old Sol ID and Branch Name filled in (and carries forward anything already collected) — just fill in the rest and re-upload. Branches are matched by Sol ID. Powers the Branch/Sol ID panel: each row shows the Manager and Recovery Officer's name with a tap-to-call number, and tapping the row opens a full card with everything on file for that branch. Uploading replaces the previous records. Goes live the next time you hit Publish.

Daily PNPA — Potential NPA (Hathras) — not loaded yet
Tap to choose the Daily PNPA file
.xlsb/.xlsx/.csv — the whole-bank Daily PNPA export as received from Head Office; Hathras rows are picked out automatically

Read entirely in your browser. Even though the file covers the whole bank, only Hathras region's rows are kept, and zero-balance accounts are dropped automatically. Powers the separate "Daily PNPA" tab — branch-wise summary split into KCC (CC004), KCC Animal Husbandry (CC043), Limit Review (any scheme flagged for a limit review) and all other schemes, sorted highest first, with a tap-through account list per branch (Account No, Name, O/S, CADU, Limit, Review Date, Reason). Uploading replaces the previous figures. Goes live the next time you hit Publish, same commit as the daily NPA data.

KCC Overdue (Hathras) — not loaded yet
Tap to choose the daily KCC "Data" file
.xlsx/.xlsb/.csv — the daily KCC "Data" export (Sol, Region, Branch, Account No, Scheme Code, Balance Amount, Cust NPA Date, F.Y., etc.); only Hathras rows and the 3 known scheme codes are kept

Read entirely in your browser. Powers the "KCC Overdue" tab — filterable by Branch, F.Y., Cust NPA Date (month or a custom date range), and scheme (KCC/CC004, KCC Animal Husbandry/CC043, OD-023 Tatkal), with branch-wise summaries, a tap-through account list, and an F.Y./Month Bifurcation, Branch Report, and All Branches Overview breakdown. Uploading replaces the previous figures. Goes live the next time you hit Publish, same commit as the daily NPA data.

Special Note (per Account No.) — none saved

Type an existing Account No. to see the borrower's name and branch, then type a note and Save — no file upload needed, one account at a time. Shown to every viewer, not just Admin, at the top of that account's Loan Detail screen. Stays on the account across daily NPA updates until removed. Goes live the next time you hit Publish.

Lok Adalat — Token Already Received — not loaded yet
Tap to choose the Lok Adalat file
.xlsx or .csv — Date, Account No., OTS Amount, Token Amount, Remark

Proposed-OTS accounts where token money has already been collected ahead of a Lok Adalat, so a viewer opening that account's Loan Detail sees a banner and doesn't collect the token a second time. OTS Amount can be left blank until it's fixed — the banner then shows Token Amount only. Matched by Account No., not Sol ID. Each upload fully replaces the previous list — only the accounts in your latest file are shown. "Clear List" empties it without needing a fresh file. Goes live the next time you hit Publish.
